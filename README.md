### 现在在做什么

- **角色先想再说** — Decide → Enact → Reflect：开口前权衡，开口后反思，关系会变
- **导演不代写台词** — 试过让导演写，所有人说话一个味。现在导演只能递咖啡和关门
- **一句话不做三件事** — NPC 同时质问身份、要手机、评外貌，不像人。单回合只做一个意图
- **从体验异味修机制** — 复读、读心、口吻同质，每一条都追到代码根因再加回归
